# 大脱獄プロトタイプ

`Assets/Scenes/Daidatsugoku.unity` を開いて Play。UI・盤面は実行時に自動生成されます。
シーンの作成メニューは `Tools > Daidatsugoku > Create Prototype Scene`（既存シーンは上書きしません）。

- 画像に合わせた5列の段差盤面。A=3、B=4、C=5、D=6、E=7マス（計25）。各列内の番号は0から。
- 左端の横オフセットはA=2、B=1、C=1、D=0、E=0。各列左端にSTART、A1の上側に監視官を表示。
- 各プレイヤーは未配置の駒を3つ持って開始。既存の任意配置ルールは維持。
- 盤上に自分の駒がなく、未配置の駒がある場合は、そのターン必ず1駒を配置。
- 盤上に自分の駒があれば「駒を配置」「柵を設置」などの行動を選択。配置先は任意のマス（同居・柵のあるマスも可）。配置で1ターン終了。
- 移動：自分の駒を選択し、右・上・下の隣接マスをクリック。
- A2/B3/C4/D5/E6から「右へ／脱獄」で1人脱獄。3人脱獄で勝利。
- 上下移動は見た目で接しているマスへ移動。段差の外や斜め方向へは移動不可。
- 柵はマスの境界に配置。設置モードでマスの辺の近くをクリックして東西南北の辺を選択。
- 初期の赤い柵5本はB0・C0・C2・D4・E2の北側境界。リトライ時にも復元。
- 隣接マスから同じ境界を指定しても柵は1本だけ。囚人の有無は設置に影響しません。
- 柵や囚人は移動を妨げません。囚人同士の同居も可。
- 破壊モードで赤い柵、または対応するマスの辺をクリックすると柵を破壊。
- P1→交代確認→P2→交代確認→P3→監視官→交代確認→P1。
- 監視官は「見ている」「見ていない」各4枚の山札をシャッフルして毎ラウンド1枚引き、使い切ると再補充。「見ていない」間は捕獲なし。
- 「見ている」場合は画像上側から下向きに全縦筋を監視。横向きの柵より下の同じ縦筋はすべて保護。
- 縦向きの境界柵は下向きの視線を遮りません。遮蔽されない囚人を捕獲。復活なし。
- 各プレイヤー3人のため、1人捕獲されるとそのプレイヤーは勝利不能。
  未配置の駒も勝利可能性に含め、全員が勝利不能になったら勝者なしで終了。未配置・盤上の駒がともになくなったプレイヤーは柵操作が可能。
- ResultのRestartで盤面・駒・柵・スコア・山札を初期化。

GameManager＝手番・勝敗、GridManager＝盤面と柵、GuardSystem＝監視、
Prisoner/GridCell/FenceClick＝クリック、FenceBoundary＝共有境界、GameHud＝UI。名前空間は `Daidatsugoku`。
UIはUGUIとInput Systemを使用。日本語はWindowsのYu Gothic/Meiryoを使用します。

## 動作検証

Play中に `Tools > Daidatsugoku > Run Play Mode Checks` を実行すると、現在の対局を
初期化して回帰チェックします。終了後は新しい対局に戻ります。
25マスと初期柵5本、共有境界、上下方向の段差隣接、列ごとの脱獄位置、手元からの配置、
ポインター経由の駒選択、不正移動、交代待ち入力ロック、柵の重複禁止・破壊、
柵より下の同じ縦筋の保護、捕獲、勝者なし終了、山札補充、
3人脱獄での勝利、結果画面の入力ロック、リトライを検証します。

2026-10-20: UnityのPlayモードで段差盤面・境界柵を含む回帰チェックPASS。
