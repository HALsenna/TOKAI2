# 大脱獄プロトタイプ

`Assets/Scenes/Daidatsugoku.unity` を開いて Play。UI・盤面は実行時に自動生成されます。
シーンの作成メニューは `Tools > Daidatsugoku > Create Prototype Scene`（既存シーンは上書きしません）。

- 4列 A–D × 横0–4。P1=A0、P2=B0、P3=C0に各3駒。
- 移動：自分の駒を選択し、右・上・下の隣接マスをクリック。
- 横位置4から「右へ／脱獄」で1人脱獄。3人脱獄で勝利。
- 柵：設置モードでマスをクリック。同じマスに囚人がいても可。既存柵との重複だけ禁止。
- 柵や囚人は移動を妨げません。囚人同士の同居も可。
- 破壊モードで柵・マス・そのマスの囚人をクリックすると柵を破壊。
- P1→交代確認→P2→交代確認→P3→監視官→交代確認→P1。
- 監視官はカードを表示して全マス監視。同じマスに柵のない囚人を全員捕獲。復活なし。
- 各プレイヤー3人のため、1人捕獲されるとそのプレイヤーは勝利不能。
  全員が勝利不能になったら勝者なしで終了。残り駒がなくても柵操作は可能。
- ResultのRestartで盤面・駒・柵・スコア・山札を初期化。

GameManager＝手番・勝敗、GridManager＝盤面と柵、GuardSystem＝監視、
Prisoner/GridCell＝クリック、GameHud＝UI。名前空間は `Daidatsugoku`。
UIはUGUIとInput Systemを使用。日本語はWindowsのYu Gothic/Meiryoを使用します。

## 動作検証

Play中に `Tools > Daidatsugoku > Run Play Mode Checks` を実行すると、現在の対局を
初期化して回帰チェックします。終了後は新しい対局に戻ります。
初期配置、ポインター経由の駒選択、不正移動、交代待ち入力ロック、囚人と柵の同居、
柵の重複禁止・破壊、同じマスだけを保護する監視、捕獲、勝者なし終了、山札補充、
3人脱獄での勝利、結果画面の入力ロック、リトライを検証します。
